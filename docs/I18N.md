# Internationalisation (i18n)

The MVP ships in **English**. The architecture must make adding Hindi, Marathi, Telugu, Tamil, Kannada, Bengali, Gujarati, Punjabi and others possible without code changes in screens.

## 1. Mobile

- Libraries: `i18next` + `react-i18next`, with `expo-localization` for the device locale.
- Strings live in `mobile/src/i18n/locales/<lang>.json` with namespaced keys:
  ```json
  {
    "scan": {
      "tabCamera": "Camera",
      "tabPhotos": "Photos",
      "detect": "Detect Disease",
      "uncertainTitle": "Unable to determine reliably"
    }
  }
  ```
- **No hard-coded user-facing strings** in components. Enforce this with a lint rule (e.g. `eslint-plugin-i18next`).
- Use interpolation and plural rules; never build sentences by concatenating strings.
- Dates, times and numbers are formatted with `Intl` using the active locale (the "Updated 10:20 am" label, temperatures).
- Language precedence: the user's saved `preferred_language` (Profile), then the device locale if supported, then English.
- Fonts: choose a font family with Devanagari and other Indic-script coverage (for example Noto Sans families) before adding those languages, and test text expansion. Hindi labels can be longer than English ones.

## 2. Backend

- Display names for crops and diseases come from `disease_classes` (English) plus an optional `disease_class_translations(class_id, language, crop_name, disease_name)` table, added when the first new language is added.
- Advisories already have a `language` column. Each translated advisory must be **reviewed separately**, because a translation is new content (ADVISORY_CONTENT.md).
- API responses accept `Accept-Language`, fall back to English, and report the language actually returned.
- Error `code`s are stable and language-independent. The app maps codes to localised messages, and the server `message` is only a fallback.

## 3. Adding a language (checklist)

- [ ] Create `locales/<lang>.json` by translation, reviewed by a native speaker with agricultural vocabulary.
- [ ] Add crop and disease name translations.
- [ ] Add reviewed advisories in that language.
- [ ] Check fonts, layout and truncation on a small screen.
- [ ] Add the language to the Profile language picker.
